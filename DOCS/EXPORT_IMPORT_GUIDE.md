# Export & Import Guide

This guide explains how to use the export and import features in the Brilliance Lead Scraper.

## Exporting Leads

To export leads from the system:

1.  Navigate to the **Leads** page from the sidebar.
2.  (Optional) Use the search bar or filters (Status, Tier) to narrow down the list of leads you want to export.
3.  Click the **Export** button located at the top right of the leads table.
4.  Choose your desired format:
    *   **CSV**: Best for importing into other tools or spreadsheets.
    *   **Excel (.xlsx)**: Best for viewing with formatting and bold headers.
5.  The system will generate the file using **Vercel Blob** and download it to your device automatically.

### Export Headers
The exported file includes bilingual support:
- **Name (EN)** & **Name (AR)**
- **Company (EN)** & **Company (AR)**
- **Role (EN)** & **Role (AR)**
- **Phone** & **Email**
- **Location**, **Tier**, **Score**, **Status**

## Importing Leads

To import leads into the system:

1.  Click the **Import** button (icon with upward arrow) on the Leads page.
2.  Select a CSV file from your computer.
3.  The system will process the file and map the columns automatically.

### Supported CSV Headers
The importer is designed to be flexible and supports both raw field names and headers generated by our export tool:

| Required Field | Supported Header Names |
| :--- | :--- |
| **Name** | `name`, `Name`, `Name (EN)`, `Name (AR)` |
| **Email** | `email`, `Email` |
| **Phone** | `phone`, `Phone` |
| **Company** | `company`, `Company`, `Company (EN)`, `Company (AR)` |
| **Role** | `role`, `Role`, `Role (EN)`, `Role (AR)` |
| **Location** | `location`, `Location` |

### Important Notes
- **Deduplication**: The system will skip leads that already exist in the database (matched by Email or Phone).
- **Encoding**: If your CSV contains Arabic characters, ensure it is saved with **UTF-8 encoding**. Our export tool automatically adds a UTF-8 BOM to ensure compatibility with Microsoft Excel.
